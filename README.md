# NIAS-Radio

![NIAS Banner schmall](images/NIASbanner.png)

A radio station that automatically reads out warnings from the BBK. As soon as an official warning is issued by the BBK, NIAS automatically processes it. After the `output.mp3` file has been generated by NIAS and is stored in `NIAS-Radio`, NIAS-Radio will automatically play it through the radio station.
> Notice: NIAS is not included, to use NIAS by itself see [NIAS](https://github.com/TeichArmband35/nias)
