# NIAS-Radio

![NIAS Banner schmall](images/NIASbanner.png)

A radio station that automatically reads out warnings from the BBK. As soon as an official warning is issued by the BBK, NIAS automatically processes it. After the `output.mp3` file has been generated by NIAS and is stored in `NIAS-Radio`, NIAS-Radio will automatically play it through the radio station.
> Notice: NIAS is not included, to use NIAS by itself see [NIAS](https://github.com/TeichArmband35/nias)

## Tech
- `Node.js`
- `FFmpeg`
- `listen2myradio.com`

## Features
- Auto play of issued warnings (file must be named `output` and must be in `mp3` format; `output.mp3`)
- Auto play of pre-recorded messages, if no warning has been issued
- Auto play of music, after reading a warning or a playing a pre-recorded message
- Icecast-Radio wont disconnect when switching to a different media (e.g.: pre-recorded messages -> music)

## Running the project
1. Install `Node.js`
2. Install `FFmpeg`
3. Install requirements for the JS file (`fs`, `child_process`)
4. Configure the JS file
5. Add music (optional, you can use the music that is coming with NIAS-Radio)
6. Add pre-recorded messages (optional, you can use the pre-recorded messages coming with NIAS-Radio)
7. Start the radio server (e.g.: start your `listen2myradio` server)
8. Run `node index.js` inside of `NIAS-Radio`

> Note: All music must be no copyright music or own a license to use a copyrighted song.
> Notice: All pre-recorded messages are in german,  because the BBK is a german Federal Office.
